# NED Home Display
Android 4.4.4+ fullscreen dashboard wrapper for http://192.168.1.114:8765/.
Keeps screen on with FLAG_KEEP_SCREEN_ON while foregrounded.
Build: GitHub Actions workflow "Build NED Home Display APK" uploads the debug APK artifact.
Caution: Android 4.4 system WebView is older than Chrome and may not display the dashboard correctly. Test before replacing the Chrome shortcut.
